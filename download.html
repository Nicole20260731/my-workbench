📱 安卓手机安装
  1. 用 Chrome 浏览器打开 Nicole工作台
  2. 点浏览器右上角 ⋮ 菜单
  3. 选"添加到主屏幕"或"安装应用"
  4. 桌面出现 N 图标，点开即可全屏使用
🍎 iPhone 安装
  1. 用 Safari 打开 Nicole工作台
  2. 点底部中间的分享按钮 ↑
  3. 选"添加到主屏幕"
  4. 点"添加"，桌面出现 N 图标
💻 电脑安装
  1. 用 Chrome 或 Edge 打开 Nicole工作台
  2. 点地址栏右侧的安装图标 ⊕
  3. 选"安装"，桌面生成快捷方式
Nicole工作台 是 PWA 应用，安装后可离线使用。
数据存在本设备+云端（需配置Supabase），不会丢失。
