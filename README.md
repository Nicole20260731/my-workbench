# 我的工作台 · 自考英语13000备考

一个个人备考 + 生活管理 Web 应用，纯前端实现，数据存储在浏览器本地。

## 功能模块

| 模块 | 说明 |
|---|---|
| 🏠 备考首页 | 考试倒计时、每日学习任务清单、连续打卡统计、备考阶段计划 |
| 📝 真题演练 | 3套真题（13000七大题型）+ 5篇作文模板库 |
| 📖 错题生词本 | 自动收集错题 + 手动添加生词 |
| 👗 AI衣橱 | 无锡实时天气 + 上传衣服照片 + AI智能搭配 |
| 🔮 塔罗占卜 | 78张韦特塔罗完整牌库 + 4种牌阵 |
| 🎋 八字命理 | 四柱排盘 + 十神 + 大运 + 旺衰判断 |

## 部署到 GitHub Pages

1. 注册 GitHub 账号
2. 新建仓库（任意名字，如 my-workbench）
3. 上传本目录所有文件
4. Settings → Pages → Source 选 main 分支 → Save
5. 等待 2-5 分钟，访问 `https://你的用户名.github.io/仓库名/`

## 添加到 iPhone 桌面

1. 用 Safari 打开上面的地址
2. 点底部分享按钮 ↑
3. 选"添加到主屏幕"
4. 点"添加"

## 文件说明
